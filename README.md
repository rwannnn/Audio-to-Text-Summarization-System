# ⬡ Audio-to-Text Summarization System
🎙️ **Intelligent Audio Transcription & Summarization Pipeline**

An AI-powered system that extracts, transcribes, and summarizes audio from video files, enabling **multilingual speech recognition**, structured transcription, and concise content summaries.

## 🚀 Key Features

### 🎧 Audio Extraction & Transcription
- Extracts audio from video files using **FFmpeg**  
- Transcribes audio using **OpenAI Whisper** for accurate multilingual recognition  

### ✍️ Automatic Summarization
- Uses **LangChain** integrated with **Qwen** and **ChatOllama**  
- Generates **concise summaries** of transcribed content  

### ⏱️ Timestamp-Based Segmentation
- Splits audio into segments with timestamps  
- Provides **structured transcription** for easy navigation  

### 📊 Applications
- Content analysis  
- Video captioning  
- Meeting summarization
